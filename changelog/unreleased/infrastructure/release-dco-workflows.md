- Two GitHub Actions workflows join the repository. `dco` runs on every pull request and fails when a commit lacks a `Signed-off-by` trailer, naming the commit and its subject, so a missing `git commit -s` is caught by CI instead of by a reviewer. `release` runs when a `v*` tag is pushed: it checks the tag against `version=` in `gradle.properties`, runs `./gradlew build` with every test, and creates the GitHub Release with `build/distributions/opensearch-lance-<version>.zip` attached and the matching `CHANGELOG.md` block as its notes. `DEVELOPER_GUIDE.md` gains a Releasing section with the four steps.
