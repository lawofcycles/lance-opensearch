- The CI `build` workflow runs `./gradlew build` in three lanes, one per OpenSearch version: `3.8.0`, the release the plugin is built for and the only required check, plus `3.9.0-SNAPSHOT` and `3.10.0-SNAPSHOT`, the snapshots of the next two minors. The snapshot lanes are `continue-on-error`, so a pull request sees an API drift in the upcoming OpenSearch versions as a red informational check instead of finding out after the release, and the test results artifact is uploaded per lane as `test-results-<version>`.
