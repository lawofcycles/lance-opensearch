- The `FragmentPlan` wire format's Substrait filter block (version 3) holds the filter bytes alone and is empty when no filter is set; the boolean that used to precede the bytes duplicated what the block's presence already said, so a plan without a filter is one byte shorter on the wire and the writer has one state fewer to keep in step. `WireVersion.Reader.finish` now fails a reader class that skipped a block of a version it knows whatever the writer's marker, so a forgotten block registration surfaces on the first message read instead of taking the fallback silently against an older writer. The `LanceNamespaceHandle.call` Javadoc names the method as the privileged choke point for every catalog type, the glue credential guidance in `docs/features.md` is a short list instead of one long parenthetical, and `LanceGlueCatalogNamespaceIT` removes its credentials file under `~/.aws` from a shutdown hook as well, so a test JVM killed mid run leaves nothing behind.
