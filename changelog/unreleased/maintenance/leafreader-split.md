- `LanceFragmentLeafReader` is split by responsibility into six package private collaborators under `engine/`: `LanceColumnLoader` (lazy column loads, the scorer hint and the sparse structures taken for it, the shard cache publish sinks and request breaker charging), `LanceDocValues` (the hinted numeric, keyword, keyword array and geo_point doc values), `NestedDocValues` (`_primary_term`, `_nested_path` and nested child field emulation next to `NestedDocLayout`), `GeoPointPointValues` (the flat single cell points tree), `LanceStoredFields` (the per hit row take and `_id` / `_source` rendering) and `LeafCacheBridge` (the lazily built one doc Lucene index that supplies `IndexReader.CacheKey`). The reader keeps the `LeafReader` contract, the fragment identity and doc id to row mapping, the public hint API and the wiring, and shrinks from about 4,000 lines to under 800. Method bodies moved unchanged; queries, settings, the wire format and every existing test are untouched.
